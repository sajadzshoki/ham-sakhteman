# هم‌ساختمان 🏢

وضعیت واقعی کد، API، ورود OTP و دیپلوی: [docs/CURRENT.md](./docs/CURRENT.md). اسناد `BACKEND.md` و `docs/DATA-MODEL.md` قدیمی‌اند.

اپلیکیشن مدرن، فارسی و راست‌به‌چپ مدیریت ساختمان — ساخته‌شده با **Nuxt 4**، **Vue 3**،
**TypeScript**، **Tailwind CSS v4** و **Nuxt UI v4**.

> برای چشم‌انداز محصول، معماری و سیستم طراحی، فایل [PROJECT.md](./PROJECT.md) را ببینید.

## شروع

```bash
# نصب وابستگی‌ها
pnpm install

# سرور توسعه روی http://localhost:3000
pnpm dev
```

## دستورهای اصلی

| دستور | شرح |
| --- | --- |
| `pnpm dev` | اجرای سرور توسعه |
| `pnpm build` | بیلد پروداکشن |
| `pnpm preview` | پیش‌نمایش بیلد پروداکشن |
| `pnpm typecheck` | بررسی تایپ (vue-tsc) |
| `pnpm lint` | بررسی لینتر (ESLint) |

## صفحات

- **خانه** — خوش‌آمدگویی، شارژ ماه جاری، دسترسی سریع، اطلاعیه‌ها
- **ساختمان** — مشخصات ساختمان، امکانات، واحدها و ساکنین
- **خدمات** — دسته‌بندی خدمات، ثبت و پیگیری درخواست‌ها (با فرم، فیلتر و تأیید لغو)
- **حساب من** — پروفایل، تنظیمات، تغییر تم و خروج
